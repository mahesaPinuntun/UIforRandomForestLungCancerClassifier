Aplikasi Deteksi Risiko Kanker Paru-Paru Berbasis AI

Sistem ini dirancang secara independen sebagai platform skrining awal objektif guna membantu menekan tingginya angka tingkat kematian akibat keterlambatan penanganan klinis.

Abstrask Machine Learning Model:

Kanker paru-paru merupakan salah satu penyakit dengan tingkat mortalitas tinggi yang sering kali tidak menunjukkan gejala spesifik pada stadium awal. Platform penapisan mandiri ini hadir sebagai instrumen digital untuk mengestimasi tingkat risiko kesehatan paru-paru secara cepat, gratis, dan terukur berbasis kecerdasan buatan.

Sistem ini memodelkan 23 parameter klinis dan gaya hidup dari 1.000 data pasien ke dalam 3 strata risiko (High, Medium, Low) menggunakan algoritma Random Forest Classifier (200 decision trees, max_depth=10, min_samples_leaf=5). Untuk menjamin ketangguhan model (robustness) terhadap masukan yang tidak presisi di dunia nyata, data dilatih dengan menyuntikkan Gaussian Noise N(0, 0.8²) dan 5% Label Flipping.

Aplikasi ini dibangun dengan arsitektur full-stack yang memisahkan Flask API (Backend) dan Vue.js 3 (Frontend) menggunakan kuesioner interaktif bertahap untuk menjaga presisi data dan keselamatan klinis pengguna.
